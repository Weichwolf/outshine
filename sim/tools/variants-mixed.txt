# FlightBox — the MIXED tournament: F-16 doctrines against MiG-29 doctrines, one arena, one fitness.
#
# Same file format as variants-bvr.txt plus one key: `module=` names the AIRFRAME a variant flies
# (default f16, so variants-bvr.txt is unchanged). A pairing between two different modules is the
# asymmetric duel of doc/duels.md run inside the tournament's own scoring, which is the cross-check
# the campaign's named missions get: the same conclusion has to survive both seats, both geometries
# and a fitness that was written before any of this existed.
#
# THE THREE DOCTRINES ARE THE SAME THREE ON BOTH SIDES, deliberately: baseline (the airframe's own
# numbers), longshot (trigger at 1.4x Rtr, designation moved out to match — a shot cannot be taken
# from further out than the lock it rides on) and deepshot (hold to 0.7x Rtr). That way the ranking
# separates the DOCTRINE from the AIRFRAME instead of confounding them.

f16_base                                                       # FBF16Pilot as it stands
f16_long    pilot_shot_rtr=1.4 pilot_lock_nm=20                # AIM-120 fired beyond no-escape
f16_deep    pilot_shot_rtr=0.7                                 # ...and held deep inside it

mig_base    module=mig29                                       # FBMig29Pilot as it stands
mig_long    module=mig29 pilot_shot_rtr=1.4 pilot_lock_nm=16   # R-27R fired into its own big Raero
mig_deep    module=mig29 pilot_shot_rtr=0.7                    # ...and held deep, the SARH price
