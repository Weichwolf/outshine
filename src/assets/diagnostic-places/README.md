# Erhaltene Weltregressionen

Diese Szenarien sind kein Teil der zwölf aktuellen Arbeits-Places. Bestehende Daten, Kameras
und Regressionen bleiben erhalten. Aufruf: outshine-client --places src/assets/diagnostic-places
shots <Name>.
Die Katalogumstellung behebt weder Lade- noch Bildfehler dieser Szenarien.
