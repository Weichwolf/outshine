## Where the axis lives, since 485daa93

measures what EXISTS -- modules, tiers, mass, stranded sources, claims -- and states no COLOUR,
because a colour is a judgement and the review is the only judge of it. **So the colour axis lives
HERE**, against the node set the CURRENT class diagram carried at 4ca42c2e, its last commit.

red one draws no pixel, so it counts in the denominator and not the numerator.
