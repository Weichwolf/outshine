# machine, so a digest proves AGREEMENT WITH OURSELVES and never correctness. Another GPU answers a
# different digest for the same correct picture. What it is FOR is a diff: a commit that was not
# supposed to move a picture and moves one says so here, in a line of text, instead of in a memory
# of what the last frame looked like.
#

# build/shots/<place>-<digest>.png, where a changed frame does not overwrite the frame it changed

# digest-named file is never overwritten, so six 720p frames a commit grow a repository
# monotonically with exactly the changes this engine is meant to make often.
