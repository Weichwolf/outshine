# A line here is a SNAPSHOT in this tree's own grading: these bytes come out of one driver on one
# machine, so a digest proves AGREEMENT WITH OURSELVES and never correctness. Another GPU answers a
# different digest for the same correct picture. What it is FOR is a diff: a commit that was not
# supposed to move a picture and moves one says so here, in a line of text, instead of in a memory
# of what the last frame looked like.
#
# The picture itself stays OUT of the tree. `build/outshine-client shots` writes
# build/shots/<place>-<digest>.png, where a changed frame does not overwrite the frame it changed
# from and the two stand side by side for an eye. Committing the PNGs was considered and refused: a
# digest-named file is never overwritten, so six 720p frames a commit grow a repository
# monotonically with exactly the changes this engine is meant to make often.
#

# once answered three different pictures -- give one digest. A line that moves here is a change,

# Four of the six moved with board:2047 and the move is QUANTISATION, not a picture. The building
# mesher now emits an indexed mesh, so a corner reaches the device once instead of three times and
# the interpolator sums the same numbers in a different order. Measured against the frames they
# replace: OldTown 217 pixels of 921 600 differ, Heidelberg 84, Venice 258, Shibuya 220 -- and
# EVERY one of them differs by exactly 1 of 255. Central Park and the Jura did not move at all.

# THOSE SIX DIGESTS WERE WRITTEN ON A BROKEN TREE AND ARE WITHDRAWN. A half-finished move of the
# sky's ambient onto the device left the CPU integration removed and the shader still reading the
# fields it used to fill, so every surface the sun did not reach went BLACK -- 6.13 per cent of
# Shibuya's frame at exactly zero and 27.62 per cent at or below 8 of 255. The six digests above are
# the tree's own, restored: no pixel is zero, and a shaded wall reads (38, 48, 50) where the sky
# above it reads (39, 71, 119).
#
# What the episode is worth keeping for: a picture was blessed into this file before it was LOOKED
# AT. The rule that catches it is already written down -- if it draws, look at it before believing
# any number -- and a digest is a number.
#
# OldTown alone keeps a NEW digest, and it is the one thing here that is not a restoration. The
# subject's fragment stage gained a storage-buffer binding for the sky's own irradiance -- bound and
# not yet read -- and a pipeline that binds one more thing rasterises to the last bit differently.
# Looked at and measured: NO pixel is zero, and the wall that reads dark in a thumbnail measures
# (44, 49, 51) against a sky of (39, 71, 119). Five of the six are byte-for-byte what they were.

# Heidelberg moved with the road's cross-section: each kerb now asks the ground where IT stands
# instead of taking the centreline's one height, so a carriageway is no longer flat across a slope.
# Seven pixels of 921 600 differ at this distance, which is what a two-lane road subtends from a
# hillside -- the change is right and small, and the defect it fixes is neither.

# ZurichPlan is not a picture of the product. It is a DRAWING: an orthographic camera 4 km above
# the ground looking straight down over 6 km of it, where a metre is a metre everywhere and there
# is no horizon to hide behind. Zurich was chosen because everything is in it -- a lake, a river,
# a dense old town, motorways -- and because anyone can say what it must look like.
#
# What it says today: the lake is NOT THERE. 73 458 OSM features are held, the buildings consume
# them, and the street field and the water field walk zero. Two of the three consumers are dead and
# a perspective view from head height hid it behind its own horizon for as long as it has existed.
