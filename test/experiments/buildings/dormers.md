## Reproduce

Use `.venv`, `TMPDIR=/tmp`, `PYTHONPYCACHEPREFIX=/tmp/outshine-buildings-pycache`
and `PYTHONPATH=lib/src:lib/tests:test/experiments/buildings:test/experiments/assets`.

```sh
.venv/bin/python -Werror -m unittest verify_dormers verify_elevations verify_roof_crowns verify_clad_facades verify_facade_frames test_reservation_query test_reference
.venv/bin/python test/experiments/buildings/dormer_probe.py --output /tmp/outshine-buildings-dormer-models
.venv/bin/python test/experiments/buildings/dormer_city.py --output /tmp/outshine-buildings-dormer-city
.venv/bin/python test/experiments/buildings/dormer_costs.py --output /tmp/outshine-buildings-dormer-costs.json --allocations
```

Render each geometry JSON with `roof_crown_render.py --geometry <file> --output
<directory-under-/tmp> --samples 16`.
Then run `dormer_review.py --models <models> --city <city> --output <file-under-/tmp>`
and `dormer_audit.py --geometry <city>/ParisDormerAfter-geometry.json --output
<file-under-/tmp>`. Freeze the producer first. The retained original actual products
are `/tmp/outshine-buildings-dormers-model-4d54994c2/` and
`/tmp/outshine-buildings-dormers-city-4d54994c2/`; image receipts are not rewritten.
