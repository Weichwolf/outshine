## Ownership and actual behavior

The [library contract](../../../lib/surface_patches.md) documents `pack_surface`
and `restore_surface`. Import the optional codec explicitly. It performs no file
IO, cache management, source acquisition or automatic geometric admission.
The existing product owner's record must bind exact known-valid generated bytes,
format and frame. Hashing unknown input or trusting its adjacent metadata grants
no validity. Unknown products require strict construction/rebuild.

Master clarified the existing AssetRecord/producer boundary in
[#678/6242803661](https://github.com/Weichwolf/outshine/issues/678#issuecomment-6242803661),
with explicit Buildings/Vegetation agreement linked in the issue. Normally
constructed, versioned generated products need no manual extra admission per
game asset and no second runtime producer. Independent cold GEOS verification
remains a research/test comparison. The experiment's externally pinned reference
protocol is not proposed as native product architecture; native integration
remains #10/#48.

The primitive `outshine-finite-surface/1` NPZ format stays byte-compatible with
the existing 78-source products: stored 1,057,733 B SHA256
`7078304b8da246d93a18a827793bb93b39d6823a7979f71243c1e3884fe9797b`,
DEFLATE 399,175 B SHA256
`cad8b87c129c79ece4985df229592284abc675330ebfc0a563e85243a9bf8d9e`.
Repacking the same strictly constructed view yields those exact bytes again.
The independently checked research reference pin remains
`ff0433accc1dd37676038f69cd44d24d4cfbce2894949dd0005925f7a6e15153`.

Restore checks the caller's digest before parsing, and checks primitive member
shapes/dtypes/capacities before numeric array loading. ZIP/NPY byte bounds,
frame/schema/identity, finite Mesh coordinates/indices and canonical active masks
remain checked. Mesh, attribute and mask buffers are byte-backed and cannot be
made writable. The added mesh freezing explicitly copies another 924,036 B on
this 78-source view. Total explicit Mesh ownership/freezing plus attribute/mask
copies are 1,961,007 B; NPZ decode, metadata, GEOS and other world products are
additional. This is a scoped copy count, not total memory traffic or RSS.
Query polygons and STRtrees are reconstructed; new geometry still uses strict
SurfacePatch construction and replacement. The codec has no SDK dependency.

## Checks and reproducibility

archive forms, byte order, immutable buffers, subsequent strict replacement,
index/scan/nearby/explicit-face queries, hash/frame/schema/mask changes, bad
indices/NaN/pickle/duplicate members and oversized or wrong-shaped primitive
headers failing before numeric decode. Rebinding an expected hash in negative
structural controls does not claim arbitrary geometry validation.

original complete products, with independent general-GEOS cold readers.
